1. About the add-on

My File Archive is designed for NVDA users who wish to store their files in an organised manner online, download them when needed or share them through a direct link. The add-on aims to make archive management easier by making frequently used operations accessible from the keyboard.

The add-on lets you connect to an account, navigate standard folders, upload and download files, copy links to the clipboard, view file information and delete files. Uploads are processed in order, so transfers are handled in a controlled manner when several files are selected.

Note: My File Archive is not developed or operated by Internet Archive. It is an independent NVDA add-on that uses the service's infrastructure.

2. How the service works

Files are stored in archive items on Internet Archive. After a file has been uploaded, the service may perform additional processing depending on the file type, size and system load. Consequently, a file may take some time to appear in lists or for derived formats to become available, even after its transfer has completed.

The add-on uses standard folders to keep files organised. These folders are provided for easier navigation and management within the add-on; the technical structure of the archive is managed in the background by the add-on.

Important: Content stored on Internet Archive is subject to that service's terms of use and policies. Using this add-on does not remove the obligation to comply with the service's content and copyright rules.

3. Storage, privacy and upload limits

3.1. File storage

My File Archive is intended to help you store files in the online archive service for the long term. However, no online storage service can guarantee that every uploaded file will be retained indefinitely.

The service provider reserves the right to remove files that violate its terms of use, are removed at the request of copyright holders or are found to contain malicious software. It is therefore important to ensure that uploaded content complies with the service rules.

Important: Keep at least one additional copy of important files that could be lost, on your computer, an external storage device or another cloud service. Always consider the risk of data loss when a file exists only in the online archive.

3.2. Privacy and copyright

Do not upload credentials, passwords, personal documents, financial data, internal organisational documents or files that you do not want shared with third parties.

Only upload files that belong to you, that you have the right to use or share, or for which you have obtained the necessary permission. Content that infringes copyright may be removed by the service provider, and repeated violations may result in action being taken against your account.

3.3. Upload limits

The service provider does not publish a fixed storage quota or total file-count limit for user accounts. Therefore, no specific storage capacity can be guaranteed through this add-on.

According to the service's technical recommendations, files in a single archive item should not exceed approximately 500 GB. Although some documents mention a range of 500–700 GB, using 500 GB as the guide is advisable for greater stability.

It is also recommended to keep an archive item below 10,000 files and 1 TB of total data. These figures are technical recommendations for more efficient and stable operation, not fixed system limits.

My File Archive uploads only one file at a time. When several files are selected, they are queued and uploaded one after another.

The pending upload queue is retained when NVDA is closed. However, a file whose transfer was interrupted does not resume from where it stopped in the next session; its upload is restarted. For this reason, especially when uploading large files, use a stable internet connection and keep the computer on until the upload has finished.

4. Opening the add-on and account operations

To use all features of My File Archive, you must sign in with a valid user account. Account creation and sign-in can be completed directly within the add-on.

4.1. Opening the main window

To open the add-on's main window, press NVDA+Shift+A.

If no active session is available, the following message is displayed:

No active account was found. Would you like to sign in or create a new account?
  • The Yes option opens the sign-in window.
  • The No option opens the main window. You can sign in later by using Account > Connect.

4.2. Signing in to an existing account

  1. In the main window, open Account > Connect.
  2. Activate the Sign in button. Its keyboard shortcut is Alt+G.
  3. Enter your email address.
  4. Activate the Send sign-in code button.
  5. Wait for the verification code to be sent to your email address. During this process, only the Cancel button is available.
  6. Enter the six-digit verification code sent to your email address in the appropriate field.
  7. Activate the Verify button or press Alt+D.

When verification is completed successfully, the add-on connects to your account and automatically refreshes the main list to display files in your archive.

Note: Verification codes can be used only once and expire after a set period for security reasons. If the code expires, you can request a new one.

4.3. Creating a new account

If you do not yet have an account, follow these steps to create one.

  1. In the Connect window, activate the Create a new account button. Its keyboard shortcut is Alt+Y.
  2. Enter your display name in the first field.
  3. Enter your email address.
  4. Activate the Send activation code button or press Alt+G.
  5. Enter the six-digit verification code sent to your email address in the appropriate field.
  6. Activate the Verify button to complete account creation.

The display name must comply with the following rules:

  • It must be between 3 and 40 characters long.
  • Turkish characters must not be used.
  • The first and final character must be an English letter or digit.
  • English letters, digits, periods (.), underscores (_) and hyphens (-) may be used between them.

The keyboard shortcut for the Cancel button in the Connect window is Alt+P.

4.4. Signing out

To sign out of the session stored on this computer, use Account > Disconnect.

This operation removes only the session information stored on the computer. Your user account, archive and uploaded files are not deleted. You can sign in again at any time with the same email address.

5. Main window, menus and folder structure

The My File Archive main window is the primary workspace for viewing and managing files in the archive. In this window, you can navigate folders, perform operations on files and access add-on settings.

5.1. Folder structure

After the first successful sign-in, the add-on automatically creates standard folders for ease of use.

Folder Description
Images Used to store photographs, drawings and other visual content.
Audio and Music Used for sound recordings, music files and other audio content.
Videos Used to store and organise video files.
Documents Used for text documents, PDF files and similar documents.
Applications Used for program files, installation packages and application content.
Compressed Files Used for ZIP, RAR, 7Z and similar archive formats.
Backups Used for files kept for backup purposes.
Other Used for files that do not fit the other categories.

These folders are provided solely for organisation and ease of access. The underlying archive structure for files is managed automatically by the add-on.

5.2. Navigating the list

Use the following keys to move between items in the main window list:

  • Up Arrow and Down Arrow move between list items.
  • Enter opens the selected folder or activates the selected action row.
  • Escape returns to the previous level from the open folder.

If a folder contains many files, its contents may be divided into pages. Use the Previous page and Next page options in the list to move between pages.

5.3. Viewing file details

When a file is selected, use Right Arrow and Left Arrow to move through its details.

The following information can be displayed:

  • File name
  • File type
  • File size
  • Upload date
  • Current file status

When you move to another file, the detail cycle starts again with the file name.

5.4. Menu structure

Menu Description
Account Contains sign-in, disconnect and main-window commands.
Settings Lets you manage notifications and file visibility options.
Uploads Lets you control ongoing and pending upload operations.
Help Provides access to the user guide and information about the add-on.

6. Uploading files and the upload queue

My File Archive uses an upload queue to transfer files to the archive in an orderly and controlled way. Selected files are queued and processed in the order determined by the add-on.

6.1. Uploading selected files

Follow these steps to upload one or more selected files:

  1. Open the folder where you want to upload the file.
  2. Open the context menu.
  3. Use Upload file. Its keyboard shortcut is Alt+Y.
  4. In the file selection dialog, choose the files you want to upload.
  5. Activate the Open button to confirm your selection.

All common file types can be uploaded. You cannot upload a file directly while viewing the root folder; first open the target folder.

6.2. Uploading files from the clipboard

Files copied in Windows Explorer or a similar file manager can be added directly to the upload queue through the clipboard.

  1. Select the file or files to upload.
  2. Copy the files to the clipboard with Ctrl+C.
  3. In My File Archive, open the target folder.
  4. Press Ctrl+V to start the upload.

If the clipboard contains valid files, new upload tasks are automatically created for the selected folder.

6.3. Upload queue and file statuses

When several files are selected, the add-on adds them to the upload queue and processes them in order. Information about pending tasks is retained when NVDA is closed.

The current file status can be displayed in the list:

Status Description
Waiting to upload The file has been queued and is waiting to be transferred.
Processing in archive The file is being transferred or processed by the service. Progress percentage is shown when available.
Upload error The file transfer could not be completed and may need to be retried.

Closing the main window does not stop ongoing uploads while NVDA continues to run. When NVDA is closed, pending upload records are retained and evaluated again at the next start.

Interrupted uploads do not resume from where they stopped. The file transfer starts again. Therefore, use a stable internet connection when uploading large files.

6.4. Managing uploads

The Uploads menu lets you control ongoing and pending transfers.

  • Pause uploads: Stops the current transfer and preserves the existing queue.
  • Start uploads: Restarts a previously paused upload queue.
  • Cancel uploads: Removes pending and ongoing upload tasks. Confirmation is requested before the operation.
  • Retry failed uploads: Adds failed upload operations to the queue again.
Caution: When an upload is cancelled, the add-on may also request removal of the transferred file from the archive service. However, the file may remain in the archive if the connection is interrupted or the service reports an error. Check the relevant folder after cancelling.

7. File management

My File Archive lets you perform various management operations on files in the archive. To access file operations, select the relevant file and open the context menu.

Status rows and page-navigation options are not actual file items. File operations are unavailable on these rows.

7.1. Downloading files

Follow these steps to download a file from the archive to your computer:

  1. Select the file you want to download.
  2. Use Download from the context menu. Its keyboard shortcut is Alt+I.
  3. In the Save dialog, select the destination folder.
  4. Activate the Save button to start the download.

While the download is in progress, only the Cancel option for stopping it is displayed. The add-on notifies you when the operation finishes successfully.

7.2. Copying a file link to the clipboard

Copy link to clipboard copies the selected file's direct access link to the Windows clipboard.

The keyboard shortcut for this option is Alt+B.

Anyone with the link may be able to access the file. Before sharing it, consider the file content and its access status.

Security warning: The direct-link feature makes files easy to share. However, remember that third parties may use the link. Use this feature with care for files containing confidential or personal information.

7.3. Viewing file information

File information displays detailed information about the selected file.

Its keyboard shortcut is Alt+D.

The information window may display:

  • File name
  • File type
  • File size
  • The file's direct access link

The information can be copied to the clipboard using the relevant button in the same window.

7.4. Deleting files

To remove a file from the archive, select it and use Delete from the context menu.

The keyboard shortcut for deletion is Alt+S.

Confirmation is requested before deletion for security. Once confirmed, the operation cannot be undone.

When the original file is deleted, removal of related derived files created by the service is also requested. This may take a short time for technical reasons.

If a deleted file continues to appear in the list, refresh the folder view or restart the add-on and check again.

8. Settings

The way My File Archive operates can be changed according to your preferences through the Settings menu. Changes are saved automatically and remain in effect in later NVDA sessions.

To change an option's state, press Enter while it is selected. Checked options are enabled; unchecked options are disabled.

Setting Description
Show notifications Provides NVDA notifications about completed uploads while the main window is closed.
Show derived files Shows in lists the additional files automatically created by the archive service from original files.

8.1. Visibility of derived files

For some file types, the archive service may automatically create additional files in different formats. For example, audio and video files may have files prepared for playback or conversion to other formats.

If you do not want to see these files, disable Show derived files. For everyday use, displaying only the original files you uploaded provides a simpler list.

8.2. Using notifications

Because uploads can take a long time, you can use notifications to monitor their status while the main window is closed.

When Show notifications is enabled, NVDA announces completed uploads through an accessible notification.

9. Important notes and troubleshooting

This section provides suggestions for resolving common issues that may arise while using My File Archive. If the issue continues, you can request support through the contact channels listed at the end of this section.

9.1. Verification code not received or unable to sign in

The verification code used to sign in to your account is sent by email. If the code does not arrive, check the following:

  • Ensure that the email address is entered correctly.
  • Check your junk, spam or similar folders.
  • If you use an organisational network, firewall or proxy server, ensure that the connection is not blocked.
  • If you requested too many codes in a short time, wait before requesting another code.

To maintain a secure connection, do not disable certificate verification.

9.2. File upload does not complete

If an upload fails, check the following:

  • Ensure that your internet connection is stable.
  • Check that the file to be uploaded is still present on your computer.
  • Use Uploads > Retry failed uploads.
  • Remember that the transfer restarts if the connection is interrupted for a large file.

For more reliable results, particularly with very large files, keep file sizes and the number of files in a folder at reasonable levels.

9.3. Uploaded file does not appear in the list

If a file does not appear immediately after upload, one of the following may apply:

  • The file may still be processed by the archive service.
  • The list may not be up to date.
  • Additional files created for the file type may still be being prepared.

To resolve the issue, close and reopen the folder view, then check again after a short time.

If you are looking for derived files, make sure that Settings > Show derived files is enabled.

9.4. Deleted file still appears

If a file continues to appear in the list after deletion, the operation may not yet be complete on the archive service.

In this case:

  • Refresh the folder view.
  • Restart the add-on.
  • Wait briefly and check again.

If the file continues to appear for a long time, the service-side operation may not be complete.

9.5. Considerations for large files

Connection quality and the computer's operating state are important when uploading large files. The following recommendations provide more reliable use:

  • Use an uninterrupted internet connection where possible during upload.
  • Prevent the computer from entering sleep mode.
  • Consider splitting very large files into smaller parts when necessary.
  • For long-running operations, do not close NVDA before the upload is complete.
